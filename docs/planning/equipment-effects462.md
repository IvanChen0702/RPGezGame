## 已實作的判定

- 弓：每一段實際造成 HP 爆擊傷害各判定一次。HP **嚴格低於**最大 HP 30% 才使用 50%；剛好 30% 仍為 35%。追加傷害以敵人最大 HP ×12% 為原始物理傷害，再扣防禦並套用既有減傷、格擋、護盾與反傷規則；不是無視防禦的真實傷害。追加本身不爆擊、不觸發主動命中／爆擊能力，不形成遞迴。
- 刃：依使用者確認，物攻加成只在本場戰鬥累積。每次 +3% 採加算，兩次 +6%，三次 +9%，不採 1.03 的連乘。連擊下一段使用增加後物攻；持續至本場結束，不因回合倒數或一般驅散而消失，不寫入角色基礎能力。爆擊零傷害／未命中不增加。
- 無敵：每次成功施放技能一次判定，含治療／增益技能，遵守現有強化封鎖規則。1 回合無敵涵蓋下一次敵方行動；競技場不會在自身施放回合末立刻消失。
- 帽：魔攻 +8% 使用既有百分比能力；不要另外在 MATK 欄填 8 來代替。15% 不進冷卻每次施放只判定一次，多段技能不重複骰；只清除本次施放技能的 CD，不清除其他技能。與同行寵物的不進冷卻能力各自獨立判定，任一成功即可。已冷卻、被封印或無法施放不判定。
- 護腕：有效直接命中後，各段獨立 25% 獲得祝福 2 回合，沿用現有祝福異常免疫及強化封鎖規則。玩家主動跳過回合，從已裝備且 CD > 0 的主動技能隨機選一項額外 -1；沒有候選時不處理。這是額外減少，不取代正常回合倒數；被暈眩／冰凍強制跳過不觸發。
- 手機與電腦使用同一個戰鬥實作；PvE 與競技場雙方均支援。神速斬擊的競技場多段爆擊標記亦已補齊，以免漏掉逐次爆擊觸發。

## 維護與驗證

- `index.html`：共用 key 解析、說明、事件與技能流程。
- `supabase/functions/game-api/index.ts`：`secureStats78` 內的 key 解析同步。此函式負責能力快照，不是逐回合戰鬥模擬器；魔攻 +8% 原有解析與計算繼續沿用。
- `node tools/check_equipment462.cjs`：前後端七種 key 解析一致、機率邊界、傷害與護盾、逐段成長與戰鬥重置、不進冷卻、無敵有效期、祝福與主動跳過，以及競技場兩側。
- 現行 Excel 同步用 `.gs` 不在儲存庫內（專案內僅有 NPC 表情用輔助 `.gs`），未核對其遠端欄位驗證或白名單。若同步器使用 key 白名單，需加入本頁的新 key 格式。
