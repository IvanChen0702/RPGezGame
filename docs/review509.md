# v509：手機整備沿用原生選擇介面

手機換裝與鑲嵌寶石不再使用桌面 `picker401` 的格子、詳情面板和確認列。設備／來源選擇仍用原有 spec，僅在 mobile 路由至原手機元件：

- 換裝沿用 `quick-picker-card`、`quick-option`：名稱、能力、強化、鑲孔與逐件裝備按鈕；保留最愛和長按資訊。
- 寶石沿用 `gem-pick-card`、`gemPickerCardHtml_`、`gemPickerListCard317_` 與原觸控處理：點擊直接鑲嵌，長按只看資訊。
- 原介面上新增稀有度、排序、搜尋與條列／格子切換。裝備預設條列；裝備與寶石各自記住檢視方式。
- 篩選／排序重新排列既有節點，動作以原物件／ID 回呼；最愛不重建視窗或清除篩選。未符合項目顯示空結果。
- 一般、競技場與迷霧來源延用原回呼與禁用條件；迷霧錯誤可顯示於手機原生框。帳號變更後不套用選擇；操作中禁用選擇與關閉。
- 桌面選擇介面及技能選擇介面維持原樣。

驗證：更新 `tools/tests/inventory504-ui.cjs` 分開測試桌面與手機介面。Chromium、WebKit 在 1440×900、390×844、320×568、844×390 通過篩選／排序、格子切換、原 ID 換裝／鑲嵌、最愛節點保留、寶石長按不誤鑲嵌、視窗比例、迷霧操作隔離及帳號切換保護。原迷霧丟棄確認與裝備比較回歸通過。人工檢視手機換裝、寶石截圖。共用戰鬥產生器、打包、diff 檢查通過。

本次只有前端調整，不需更新 Apps Script 或資料庫。
