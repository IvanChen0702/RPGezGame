## 變更

- 成就 451 另見 [成就調查](achievements451-investigation.md)。
- 排程以「單一拳擊賽季」及「世界 Boss 清理」為各自持鎖單位，單位之間解鎖；仍使用玩家寫入的同一把鎖，保留既有舊版寫入互斥。
- 保留所有歷史賽季補發檢查。發獎查詢僅取依原排序的前十名 account_id／nickname，不下載 build snapshot。
- 排程單位在下一次 I/O 前檢查 8 秒預算；排程讀取上限 5 秒，寫入保留原 15 秒上限。這是合作式截止，不是強制中斷資料庫交易或保證 8 秒必定結束。
- 新增固定階段名稱的 job_started／job_succeeded／job_completed，以及每單位持鎖時間、解鎖結果。釋鎖未確認則停止下一單位，不以新 lease 遮蓋前次異常。
- 主線／副本結算僅在明確 `429 + SERVER_BUSY` 時，以已保存的同一 battleId、requestId、summary 等待 2 秒後重試，最多兩次。網路逾時、503、未知結果不自動重送；原本的查詢恢復、版本核對、手動確認仍保留。換帳號會停止重試。
- 無 SQL migration、授權變更、lease 強制清除、手動執行排程或清理。世界 Boss 清理仍沿用原排程與規則。
