# 手機成就頁籤調查與防護修正 451

玩家回報：點選成就分類時閃一下，之後內容空白、無法切換。

## 調查結果與限制

- 修改前在 Chromium 與 Playwright WebKit，以合成成就及手機觸控方式測試，正常資料可切換；未重現玩家描述的「持續整頁空白」。WebKit 模擬不等同於該玩家的實體 iPhone／Safari 版本。
- 原本每次點選分類都呼叫全站 `render()`，重建整個 `#page`、頁籤、捲動清單，並執行其他畫面的共用更新。這是已確認的程式行為；尚不能據此認定就是玩家空白的唯一原因。
- 原選中的「其他」分類若在企劃更新後沒有項目，頁籤會被隱藏，選取值卻仍維持 `other`，導致沒有任何已選中的可見頁籤。現在會回到等級成就。
- 390×844、320×568、844×390 的手機佈局下，完整清單與各分類可顯示，未觀察到清單高度被壓成 0。沒有因此擴大修改共用 CSS。
- WebKit 初次建立城鎮時可觀察到既有 ResizeObserver 通知；沒有證據顯示這個通知造成成就空白，也未將它當作本次根因。

仍缺資訊：受影響手機型號、OS／瀏覽器版本、全部或特定分類、是否在領獎／旋轉／切回遊戲後開始發生。未存取玩家帳號、存檔或執行正式領獎。

## 本次變更

- 分類切換先在離線 DOM 建立新內容，成功後才更新成就清單與統計，保留視窗、面板、分類按鈕與捲動容器，避免全站重畫。
- 切換分類將清單移回頂端，保留分類按鈕焦點；動態新增／移除分類與項目數仍會同步。
- 新內容產生失敗時保留原內容與選取分類，顯示可重試提示；再次成功切換時清除提示。診斷只記錄分類、介面模式、視窗尺寸及錯誤類型，不含帳號、token 或存檔。
- 非成就頁面或無效分類的晚到事件不再觸發全站重畫。沿用原領獎函式及獎勵資料。
