# 世界 Boss 449／競技場 450 上線驗證

使用者已確認世界 Boss 設計，並要求與電腦版競技場問題一起上線。

## 修正

- 桌面競技場使用 `hubUI413_.facility`，原排行榜回應只檢查手機／舊版的 `arenaTab_`，因此快取更新後沒有重畫。現在依目前顯示的頁籤更新，首次進入排行與復仇頁籤也會讀取尚未載入的資料。
- 復仇清單受舊版 `flex: 1 1 0 !important` 影響，在桌面自動高度視窗內被壓成 0。桌面清單改用自然高度，由視窗內容區負責捲動；手機樣式維持不變。
- 排行與復仇讀取完成後先解除 busy，再重畫；區分未載入、讀取中、失敗與空清單。失敗保留前次資料，切換帳號／替換快取後不套用舊回應，關閉視窗或切換頁籤不會被舊回應拉回。
- 整合已核准的世界 Boss 介面：既有背景與敵人素材、討伐情報／排行／獎勵三頁籤、固定底部操作。世界 Boss 排行也改在解除 busy 後重畫，避免新版按鈕一直停用。
- 原本的 3 秒更新防連點機制維持不變。此次只修改前端，無 SQL、權限或後端部署。

## 驗證方式

在儲存庫啟動本機 HTTP server，執行：

```sh
python -m http.server 8443 --bind 127.0.0.1
# 另一個終端機
node tools/check_arena450.cjs
python tools/package_site.py
git diff --check
```

瀏覽器測試封鎖外部連線，使用合成玩家與 API 回應，保留正式讀取函式、頁籤、DOM 與 CSS。涵蓋立即更新、首次載入、重複請求、錯誤／重試、空清單、晚到回應、正確 revengeId、手機刷新及世界 Boss 實際讀取／開箱確認入口，不執行線上戰鬥或開箱。

- 競技場：1440×900、1280×720、1024×600，30 筆復仇資料最後一列可捲至並點擊；390×844 手機排行與復仇刷新。
- 世界 Boss：1440×900、1280×720、1024×600、1920×1080，三頁籤及底部操作均在視窗內，無水平溢出。
- 另以現行企劃資料搭配合成玩家驗證 11 隻 Boss 素材正常載入且保持比例；已擊敗、結算待確認、次數耗盡、無寶箱狀態及手機原 renderer。
- 正式打包檢查公開檔案與 Cloudflare Pages 單檔限制；未使用真實玩家帳號做交易驗證。
