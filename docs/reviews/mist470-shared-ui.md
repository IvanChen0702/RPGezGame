# 迷霧戰境共用介面整合（470）

原本戰境另寫戰鬥與行囊畫面，沒有使用完整戰鬥舞台、裝備管理與換裝流程。此次移除獨立戰鬥模板和行囊格子，改由現有 UI 接收戰境資料。

## 畫面與操作對照

| 流程 | 沿用元件／處理 |
| --- | --- |
| 入口、規則、棋盤、插旗、隱身 | 保留既有核准的戰境場景、圖示與棋盤操作；頁面內捲動，手機導航不覆蓋內容 |
| 遭遇玩家、怪物、寶箱、補給站、鐵匠鋪 | 共用 modal；鐵匠鋪入口直接開啟裝備配置 |
| 裝備配置 | prepare-equip-area、decorateEquipViews205_、drawPaperdoll204_，八個欄位使用現有框與角色形象 |
| 能力、技能 | arenaDefenseStats331_、arenaSkillsEditorHtml_；模式數值獨立，技能只能選已解鎖項目 |
| 換裝、切換技能、選擇寶石 | openPicker401_，保留現有詳細資料、取消、確認與鍵盤操作 |
| 背包 | bag402_ / market402_，沿用裝備格、分類、搜尋、條列及詳情；手機詳情開在共用 modal |
| 已穿戴裝備管理 | 換裝視窗增加「管理目前裝備」，沿用 openItem / item-manager307 |
| 強化、鑲嵌、拆卸 | 共用裝備管理及 gemSlot310_；回呼改為戰境 API，保留鐵匠鋪距離、體力與背包容量限制 |
| 寶箱、寶石、待收戰利品、丟棄 | 共用物品詳情與確認框；寶石可丟棄，不會卡死容量 |
| 怪物／玩家戰鬥 | renderArenaBattle_、desktopBattleHtml410_、pixelRender192_，共用背景、落腳位置、血條、狀態、技能列、倍速、自動與戰報 |
| 戰鬥演出 | 共用技能特效與浮字；只對伺服器明確記錄的敵人攻擊播放動作，不由 HP 下降推斷攻擊，避免反傷衝刺 |
| 戰鬥結算、恢復 | 共用結果畫面與返回按鈕；手機戰鬥及結算期間均無主導航，返回棋盤才恢復 |
| 排名、賽季獎勵 | 共用競技場排名列與 rankRewardLootHtml_；領獎仍用原本經驗證的交易流程 |
| 戰報、死亡、重生 | 保留既有紀錄／重生流程，使用同一個可捲動的內容容器 |

## 資料邊界

- arenaBattle_ 僅是戰境畫面的呈現資料；mist470 標記將施放、跳過與結算轉回 mist/*。不提交 arena/battle/submit，不在前端再算一次傷害。
- 共用背包、裝備與選擇器透過可選來源／回呼接入；一般角色省略來源時維持原本路徑。
- 隱藏戰境裝備的正式最愛控制，不套用正式配點、寵物、道具或正式庫存。戰境只有賽季領獎會走原本的正式存檔交易。
- game-api 回應新增自己的戰鬥 stats、buff、passive、arcaneStacks，及對手已清理的外觀；不公開對手能力、技能或裝備清單。
- 不需 SQL、企劃重發或 Apps Script 更新。部署前已比對線上 game-api v62 五個檔案與 main 一致並另存備份。

## 驗證

- tools/tests/mist470-play.cjs：使用真實 reducer 的合成帳號，測試參賽、旗幟、移動、隱身、出生補給、換裝、技能、數值、背包、已穿戴管理、強化、回覆遺失後同筆重試、鑲嵌／拆卸、開箱、怪物及玩家戰鬥、刷新恢復、逾時結算與返回。
- 在流程前後比對正式裝備、寶石、金幣、技能與寵物資料。所有測試封鎖外部網路，不操作正式玩家。
- Chromium / WebKit：1440×900、390×844、360×640、844×390 操作測試；入口、棋盤、排行、戰報與捲動另含 1366×650、768×1024。
- supabase/tests test:mist：交易／恢復／資料隔離、PvP 死亡掉落與復仇、供給與怪物、320 組共用戰鬥案例及 30 回合限制。
- 新增戰鬥回應資訊隱私驗證；test:lease 83 項授權與鎖流程檢查。
- check_arena450、check_equipment462、check_battle_pet458：既有競技場、裝備特殊能力、敵人提示與寵物訓練回歸。
- WebKit 為本機瀏覽器核心測試，非實體 iPhone；初始化切換介面時既有 ResizeObserver 警告與互動期例外分開記錄。

## 部署

先部署相容的 game-api 回應欄位，再合併 main 觸發 Cloudflare Pages；以正式前端與本機公開成品逐位元比對確認上線。
