# 迷霧戰境回合與狀態修正 494

## 原因與改動

- 共用戰鬥頁面的迷霧包裝器主動移除了 `enemyBattleStats`；API 投影與逐事件快照也未提供對手能力。恢復戰鬥中的數值列與逐事件公開能力／增益；棋盤仍只揭露原本允許的玩家資訊，技能配置、裝備、AI、帳號、背包不新增公開。
- 伺服器產生器採用競技場開局結算：中毒 5%、燃燒 4%，且把所有異常當回合型扣除。改依一般戰鬥的階段：玩家行動後、敵人攻擊前，先結算敵方燃燒／中毒，再結算玩家中毒／燃燒。讀取共用 StatusEffects（現行中毒 2%、燃燒 5%）；層數型狀態持續至淨化／戰鬥結束，不顯示假的剩餘回合。
- StatusEffects 原伺服器解析漏掉 durationType、effectType、stat、description，且未正確正規化布林欄位。抽出前端原有 `applyStatusRows494_` 並由產生器直接共用，保留 Excel → GS → published planning 流程。
- 技能再生改在對方行動結束、增益／護盾結算後觸發；玩家施放的當輪即可觸發一次。敵方玩家採鏡像規則，在挑戰者行動結束觸發。裝備／寶石明確標示「回合開始」的回血仍保留回合開始。禁療、詛咒、封鎖強化沿用既有恢復判定；修正普通恢復術在禁療／詛咒時漏建持續恢復。
- API 與動畫快照補上再生狀態；前端不再把 regenTurns 清成 0，每個事件同步狀態區與血條，而非等待整輪結束。
- 逐項盤點現行 StatusEffects 的回合／層數／觸發類型。回合型異常不在剛施加的階段立刻扣除；格擋只在承受有效傷害時消耗。護盾、增益與無敵在對方行動完成後扣除；冰凍／麻痺會保留該輪停止 CD 的判定。
- 補齊封印選格、伺服器拒絕施放及共用技能按鈕禁用；失血在成功施放技能後扣血，跳過不扣。修正破防固定倍率、失明爆擊率、忘卻中的攻擊被動、烙印傷害倍率，以及普通怪攻擊未讀取乏力／壓制／破防的問題。
- 一般戰鬥的主動跳過及控制跳過原本漏扣敵方異常。以每回合一次的共用入口補齊，避免用不同操作方式延長敵方異常。

## 回合規則核對

| 類別 | 本次核對 |
| --- | --- |
| 中毒、燃燒 | 共用企劃百分比 × 最大 HP × 層數；玩家行動後、敵人攻擊前；無回合到期 |
| 再生 | 對方行動完成後回血一次並扣一次剩餘次數；保留禁療／詛咒與封鎖強化 |
| 冰凍、暈眩、麻痺 | 控制跳過不施招；冰凍／麻痺暫停該輪自然 CD，暈眩不暫停 CD |
| 乏力、壓制、破防、失明、忘卻、封印、失血、禁療、詛咒、烙印、封鎖強化 | 核對時效與新附加狀態保留；修正上列缺失的套用／顯示 |
| 祝福、無敵、技能增益、護盾 | 保留完整對方行動的防護，完成後扣次；無敵免疫敵方附加異常 |
| 格擋 | 觸發型，不因回合自然消失 |
| 暗蝕 | 層數型不倒數；現行為主線／極限特定 Boss 機制，未新增至迷霧怪物或技能 |
