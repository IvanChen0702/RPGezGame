# 489 厚石地城實作

依已確認的 A「厚石地城」預覽，將場景接進正式棋盤 DOM。角色、怪物、旗幟、補給站、鐵匠鋪、資源箱與共用帳號橫幅沿用現有素材與程式。此變更只涉及前端及兩張背景素材，不修改 Supabase、GS、企劃或玩家資料。

## 場景與操作

- 外牆由新背景的四邊切片繪製，放在棋盤格外。上方 156、左右 102、下方 124 像素為場景邊界，不占任何出生點或可行走格；沒有隨視野生成的牆。
- 石造拱廊、柱體、火把均來自核准背景。地面擷取同一背景的純石板區，四象限鏡射拼接為連續材質；固定紋理尺度、地圖擴張時不把地磚拉大。
- 64px 棋格保留原本點擊、資訊小窗、整備入口、移動動畫、插旗與視野切換。位置定位和移動表演仍從實際棋格 DOM 計算，不以額外偏移硬編碼。
- 棋格腳下增加陰影、保留選取與可移動框；旗幟計時標籤保持在各自格內。
- 霧使用 8×8 格的小區塊，完全未見區域只畫底色；可見邊界才產生局部 SVG 遮罩。濾鏡最多含周邊各一格，不建立整張擴張地圖尺寸的模糊表面；靜態霧層沒有持續動畫或新增定時器。
- 可見資訊仍完全依伺服器 `cells` 決定。霧層只作裝飾、不接收點擊，不會建立隱藏玩家／物件。未見區域僅可能透出少量固定地面紋理。
