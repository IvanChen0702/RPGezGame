# 迷霧戰境結算整備與敵人情報 495

- 戰鬥結算「返回棋盤」旁新增「開啟整備」，沿用原有三分頁整備視窗。桌機沿用共用結算操作列；手機採等寬雙欄，320px 仍並排。
- 先使用原 battle/leave 請求確認離開戰鬥，再開啟整備；若有未完成的戰利品開箱，先沿用現有開箱／一鍵裝備流程，領完後自動開啟整備。連線失敗保留同一 requestId 重試，未確認成功不開啟整備。死亡時停用並提示先回棋盤重生。
- 修正桌機結算轉換器丟棄原本外掛錯誤區的問題：錯誤訊息及重試操作一併留在共用結算內容內。
- 敵人情報改為血條、單行基本能力、行為與技能、目前效果的閱讀順序。技能描述依換行／分號分列；無效果顯示簡短空狀態，移除空 panel、框外說明與共用捕捉器重複插入的效果區。
- 小窗高度依內容調整，超出螢幕可捲動；使用既有 HP、狀態標籤、整備與結算元件。玩家對手未公開的技能／裝備保持不公開。
- 樣式與標記限定迷霧情報窗，關閉或切換其他迷霧小窗時清除，避免影響其他模式。

驗證：`node tools/tests/mist495-ui.cjs`，Chromium 與 WebKit，1440×900、390×844、320×568、844×390；實際點擊戰鬥問號，檢查單一效果區、說明分列、視窗邊界／留白、返回／整備、離開失敗同筆重試、死亡防護、開箱確認後接續整備。隔離 fixture 模擬請求，不操作真實玩家。內嵌 JS 產生器解析、diff 檢查與 Cloudflare 打包通過；後端產生檔無差異。本次不涉及資料庫、企劃或 GS。
