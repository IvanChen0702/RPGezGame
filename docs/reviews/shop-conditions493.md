# 商店條件提示 493

商店完整列出 ShopEntries 啟用商品，不再以主線進度、技能持有或永久道具持有狀態隱藏商品。維持各商品分類、圖片、名稱、描述與價格；不新增已停用商品、不更動企劃或後端購買規則。

- 購買操作區改顯示未達條件：主線通關層數、前置技能、已習得／進階技能、已持有永久道具；其他條件已滿足而金幣不足時，顯示差額。
- 解鎖判定沿用 `max(floor,maxCleared+1) >= ShopEntries.UnlockFloor`；例如 UnlockFloor=30，提示「通關主線第 29 層後開放」。不拿裝備評價 Lv 當購買等級。
- 電腦城鎮商店顯示於右側詳情底部與物品提示小窗；手機／一般商店清單顯示於卡片底部，與價格同列，條件可換行。圖片不反灰、不壓縮。
- 條件符合時恢復原購買／升級按鈕與批量購買流程。購買入口及批量視窗也使用相同條件檢查，避免新顯示的未解鎖商品在離線模式或舊控制項中被購買。
- `utility` 商品分類歸入消耗品；不影響同名的實際裝備（如目前招財戒指）。

驗證：`node tools/tests/shop493-ui.cjs`，Chromium 與 WebKit 各 1440×900、1024×768、390×844、360×640、320×568。測試全商品保留、技能前置與通關邊界、持有狀態、金幣差額、條件達成後的購買請求、過期控制項阻擋、長名稱換行及離線商品。無橫向溢出或 JS 錯誤；完整內嵌 JS 語法與 Cloudflare 打包通過。
