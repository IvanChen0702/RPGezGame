# 副本入口整合版（491）

依核准的桌機／手機設計，使用既有森林入口背景、副本王像素形象、裝備 icon、共用能力與功能圖示組成實際介面。沒有新增或修改美術檔，全站玩家橫幅與桌機森林入口行走流程保留。

- 桌機：左側五隻王的選單，右側形象、難度、回合限制、能力、技能與掉落。整合舊「關卡情報／掉落內容」頁籤，避免選取同一目標時來回切換。
- 手機：橫向可捲動選王列，內容區垂直捲動，最後整備操作列固定在內容區之外；底部原有導覽保持原流程。
- 基礎能力沿用 `battleIcon199_`，只有圖示、文字與數字，沒有獨立框線或底色。手機排成兩行。
- 王名、開放時段、可選難度、能力、技能、特殊規則、裝備與掉落率皆來自現有企劃。沒有使用設計稿的示意值覆蓋資料。
- 技能摘要從原文分句，顯示前兩項；完整技能與掉落細節繼續用 `showDungeonBossInfo_`／`switchDungeonBossInfoTab_`。特殊規則保留在主畫面，長內容可捲動。
- 選王／難度仍用原本的選取函式，重新繪製後保留選單捲動與鍵盤焦點；最後整備繼續走 `startDungeonChallenge_`、`requestReadyRoom24_`，未變更開戰或結算邏輯。
