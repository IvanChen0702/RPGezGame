# 戰境表演與整備互動修正（471）

470 只共用戰鬥模板，仍先套用整回合結果，再由文字紀錄補播一次施放與總傷害。這會漏掉連擊、施放與命中的順序，且結算可能先於最後動作出現。整備也繞過一般關卡的裝備選單、手機快速配置與技能欄。

## 修正

- 共用 combat 核心原本被忽略的 `arenaVisual_`、施放、效果浮字、反射、元素、骰子與等待等呼叫，改為紀錄本回合的表演事件；傷害與判定仍由原有核心執行。
- 前端依事件順序呼叫既有戰鬥表演，逐擊更新 HP、護盾及狀態。演出期間保留原本的戰鬥資料與操作鎖；最後才切換伺服器結果及結算畫面。桌機、手機共用同一流程。
- 事件不再由 log 字串推測。反射是獨立力盾事件，不播放突進。多段魔法每一擊都有自己的命中與 HP 狀態。
- 隱藏分頁、降低動態效果、離開或切換帳號時停止播放；不重算、不重送戰鬥。舊後端回應缺少事件時只顯示已驗證結果。
- 一般整備的 `openEquipMenu206_`、`openPrepareEquipPicker`、`openPrepareSkillPicker`、`prepareSkillSlotButton` 以可選資料來源接入戰境。手機使用原本快速配置清單；桌機使用原本選擇器。共用長按／滑入說明、邊框流光與能力列。
- 角色畫布以整個裝備場景置中，清除 grid 區域對絕對定位的影響；沿用共用人物合成與待機 renderer。一般性別切換控制保留，沒有加入寵物或配點功能。
- 沒有換裝的狀態刷新保留同一張人物畫布與待機動畫；行囊保留捲動位置，開啟操作選單時暫停背景刷新。
- 修正隱藏敵人能力數值時，血量文字沒有移入共用血條的問題；戰境／競技場被動圖示改讀目前戰鬥配置。

## 資料與驗證

每回合事件獨立重置，上限 512 筆，不累積整場歷史。事件只包含已公開的攻擊、文字、HP、狀態、護盾，以及自己的能力；不附對手完整能力、裝備、AI 或未施放技能。

- 與修改前的核心逐一比對 32 個已啟用主動技能：最終完整戰鬥資料與 log 相同（排除新增事件欄位）。
- `mist-playback471.mjs` 驗證砍擊、魔法彈 II／III、魔力爆發、反射、逐擊 HP、每回合重置與對手資訊隔離。
- 操作測試增加實際 `arenaVisual_` 呼叫順序、多段魔法實際演出數量、結算延後、人物置中、刷新保留 renderer、性別切換僅一個 renderer，以及原有管理／更換選單。
- Chromium／WebKit：桌面、手機直向、窄螢幕、橫向；一般整備與競技場另外做回歸檢查。WebKit 不是實體 iPhone 測試。
- 使用合成帳號與本機企劃，不以正式玩家進行測試。

不需 SQL、企劃發布或 `.gs` 更新。後端先部署相容事件欄位，再發布前端。

## 實際並排比對與補充修正

- 用相同敵人素材、背景、能力與技能，分別執行一般關卡的 `useSkill` 和戰境的伺服器事件播放。不是僅檢查呼叫數：監測共用 canvas 的四發 `skill386` projectile，以及實際 animation frame 中怪物的 attack／hit 和玩家的 hit。
- 補回一般關卡的施法起手、連擊間隔、回合收尾與敵方起手等待。共用 `BATTLE_PRESENTATION471_`，原一般戰鬥的等待數值不變，避免上一招的施法姿勢遮住受擊動作。
- `skillButton` 加入可選資料來源，戰境使用同一個技能按鈕模板。空技能欄、跳過回合、撤退位置沿用原配置；戰境禁止的消耗品和戰中撤退保持停用。正式角色的消耗品不會混入戰境圖示。
- 手機長按 480ms 顯示裝備說明，抬手後不誤開管理／更換；桌面沿用滑入說明及點擊管理／更換。
- 逐項量測兩種流程的戰場、血條、技能列、倍速、自動戰鬥、跳過及撤退之位置與尺寸。修正桌面空技能欄多套框線造成 12px 寬度差，以及橫向手機控制列的遺留滿寬樣式。
- 仍依戰境原規則隱藏對手能力、裝備與未公開技能；保留 30 回合上限、戰後 HP、不使用正式配點／寵物／消耗品。這些規則不因視覺共用而改變。

## 寶箱流程

- 行囊移除寶箱分類。加入或重生後首次點棋盤，自動開啟附近的私人補給；戰鬥結束且表演播放完成後，自動打開戰利品寶箱。舊版保留的箱子與待收區箱子也可恢復處理。
- 沿用現有 `giftCeremony431_`／`giftReveal431_`／`giftComplete431_` 的完整寶盒開啟表演、略過按鈕、結果卡及響應式布局。
- 在既有 mode runtime 儲存已發放的開箱結果，重新整理／斷線不重抽。`chest/confirm` 用既有請求收據和修訂號，支援收下或一鍵裝備。
- 一鍵裝備只處理此箱仍持有的物品；替換裝備移入行囊，已滿則保留於待收戰利品。不消耗體力，不重置 HP；死亡清除失去的物品及其開箱結果。
- 戰鬥重試沿用同一筆請求，確認後仍播放完整的事件序列。開箱或確認發生版本衝突時可更新戰況，不困在結果視窗。

新增 `mist-chests471.mjs`、`mist471-chests.cjs`、`mist471-comparison.cjs` 和 `preparation471.cjs`；SQL 交易測試補驗證開箱結果持久化及確認請求的去重。瀏覽器測試包含丟失回應、開箱動畫途中重新整理、重生、一鍵裝備與戰鬥勝利後的自動開箱。
