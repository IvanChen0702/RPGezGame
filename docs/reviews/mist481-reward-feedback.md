# 迷霧戰境 481 獎勵回饋

## 排查

玩家回報 PvP 勝利、返回棋盤也沒有開箱。唯讀檢查最近兩場玩家進攻勝場的防守裝備快照：皆為四件重生補給，沒有一般可掉落裝備。未輸出玩家身分或完整存檔。

現行 transferDrops 排除 starter；可掉落裝備為零時不建立寶箱。以實際 reducer + 瀏覽器測試帶一般裝備的對手，桌面／手機皆在最後一擊與結算後自動開箱。此次不新增空箱或複製出生裝備。

## 修正

- PvP 結算保存實際掉落數量及無掉落原因，勝利畫面明確說明「對手沒有可掉落裝備，本次未獲得寶箱。重生補給裝備不會掉落」。只依該場交易結果，不由前端猜測。
- 共用資訊窗關閉後重新檢查待開寶箱，避免結算時開著資訊窗而需等定期更新。
- 補給站取得寶石後開啟既有寶石資訊卡，顯示名稱、圖示、數值／特殊能力及背包或待收位置。
- 保存最近一次實際補給收據；遺失回應及刷新可恢復同一筆結果。確認只在本機記錄已讀，不再授予或重抽寶石。只投影本人收據。
