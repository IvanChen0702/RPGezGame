# v508：全平台關卡入口鎖定樣式

- 城鎮傳送門的模式選擇按鈕、右側進入按鈕，以及手機／獨立戰鬥入口的模式卡片，共用既有 `modeUnlocked258_` 和 `modeUnlockMessage258_` 判定。
- 未達條件時設定原生 disabled、aria-disabled 與提示文字；灰階、降低亮度、移除發光／按下表演，保留解鎖條件。
- 主線／挑戰地圖的不可挑戰節點、未解鎖章節與已停用的進入按鈕也反灰；第 10 層前不可重打的既有規則維持。
- 已解鎖後重新繪圖自動恢復樣式與點擊；不關閉分類頁籤，以免同分類中已開放模式無法選擇。
- 模式啟動函式保留解鎖防線，即使直接呼叫也不會播放鎖定模式的進場流程。

驗證：`tools/tests/entry508-locks.cjs` 在 Chromium／WebKit，1280×720 桌面、390×844 與 320×740 手機通過。涵蓋主線進度 0／1、9／10、19／20、29／30、47／49／50 的模式門檻、原生停用及灰階、混合開放競技分類、章節／關卡節點、未就緒企劃。人工檢視桌面及窄手機畫面。共用戰鬥產生器、靜態打包及 diff 檢查通過。

本次只調整前端入口互動與樣式，解鎖數值仍來自現行企劃。無資料庫或 Apps Script 更新。
