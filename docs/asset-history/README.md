# 素材歷史資料

此處四份 JSON 原先位於公開 `data/`，目前前端沒有載入它們。將其保留作為開發參考，避免和遊戲執行期資料混淆。

- `asset-review.json`：歷次素材檢視與替換紀錄。
- `asset-path-migration.json`：早期檔案搬移與別名紀錄。
- `icon-index.json`：歷史圖示索引。
- `mode-npcs413.json`：場景 NPC 的設計參考；正式 UI 使用 `index.html` 內嵌定義。

這些是歷史快照，可能包含已退役檔名，不能當作目前的載入清單。正式對應以 `index.html` 的 `assetRegistry393_`、最終圖示對應與企劃資料為準。
