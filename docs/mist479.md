# 迷霧戰境 479：棋盤素材、移動表演與戰報

## 變更

- 保留共用帳號橫幅，模式內使用原有地城入口色調、石框、連續石板棋盤及精簡控制列。HP 與體力均以條狀及數字呈現；體力新增圖示與伺服器提供的下一次恢復時間。
- 可見旗幟常駐計分倒數，玩家站在旗格仍顯示小旗與時間。交戰中顯示標籤；尚未生成的怪物只顯示法陣及倒數。敵人、玩家、旗幟、建築資訊採點擊小窗，玩家僅顯示既有公開資訊。
- 新增一般／傳說裝備寶箱的關閉及開啟圖，沿用 gift431 的光效、跳過、結果卡、一鍵裝備與重試收據。新圖依分類放置於 assets/images/ui/mist，來源與雜湊見 assets/mist479.json。
- 移動取得伺服器成功回應後，沿用城鎮角色行走骨架，在兩格之間播放 360ms 位移，再套用權威結果。期間仍鎖住同筆請求，失敗不先移位；減少動態設定直接更新。切頁、帳號切換及背景頁會終止表演。
- 戰鬥開戰時保存遭遇座標，結算、死亡或重生不會改寫歷史座標。既有進行中戰鬥在結算前從目標格補取；無法取得的舊戰報明確標示未記錄。
- 拔敵旗同一交易內寫入拔旗者與旗主戰報，包含座標、事件後積分；失敗不寫入，自己撤旗不冒充被敵人拔除。駐守計分戰報亦有座標。

## 相容性與部署

只有 index.html、圖片及 game-api 的 mist-runtime468.js 需要更新。無資料庫結構、授權、企劃數值或 .gs 變更，無須填表。舊版前端可以忽略新增的 position、energyNextAt、legendary 欄位。

舊資料不推測戰報座標；既有傳說寶箱收據可依既有名稱辨識新圖。玩家、裝備、積分與寶箱生成規則不變。
