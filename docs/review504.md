# v504 整備操作與介面預覽

正式來源仍為 index.html。底部操作列、敗北通知及重生頁目前僅為待確認的設計預覽，未接入正式頁面。

## 已實作的功能

- 前端「行囊」統一稱為「整備」。
- 迷霧整備物品資訊的管理按鈕下增加紅色丟棄；使用現有確認視窗，確認後再次核對帳號、物品及操作狀態，沿用原指令重試機制。
- 桌面迷霧裝備懸停顯示目前同部位裝備；戒指以最高裝備 Lv 比較，強化等級只用於同 Lv 排序。
- 一般換裝及鑲嵌選擇共用現有選擇視窗，加入稀有度、搜尋、排序及格子／條列。篩選排序後仍依原物品識別值執行操作。

## 預覽

執行 `node tools/previews/mist504.cjs`，需本機 8443 靜態伺服器。以現有角色、場景、圖示及結算素材呈現；預覽資料不連線正式 API。

- 桌面：HP／體力上下排列、等高等寬，三個主要操作按鈕放大，底列固定。
- 手機：HP／體力上下排列，積分並排；主要操作與視野切換分列，棋盤獨立捲動。
- 敗北：對手、座標、台灣時間與積分／物品／旗幟摘要。
- 重生：補給箱、四部位裝備示意、滿血／體力／保護資訊。
