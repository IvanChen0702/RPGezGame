# 城鎮同行寵物（436）

前端已支援在線玩家的同行寵物。正式 Supabase 尚需執行此更新：

1. 開啟專案 `ynzaotitxntrhubwfinr` → SQL Editor → New query。
2. 貼入 `migrations/202611130001_town_companions436.sql` 全文，執行一次。
3. 重新整理遊戲，用兩個已登入帳號進入城鎮。各自攜帶不同寵物，確認另一個帳號身旁顯示正確寵物；取消攜帶後，等下一次在線名單更新（約一分鐘），寵物應消失。

函式沿用既有 `game_town_presence420` 的認證、名單、排序及在線時限，依回傳的遊戲帳號 ID 讀取 `PlayerSaves.save_json`，只追加已裝備寵物的 `id`、`species`、`level`。不新增資料表、不改存檔、不公開其他寵物或能力資料。既有 420 API 保留，舊版玩家仍可使用。

尚未安裝時，前端遇到新 RPC 不存在會沿用舊名單，每五分鐘重新探測一次；安裝後重新整理可立即重試。其他認證或網路錯誤不會觸發降級。此資料夾不會打包至 Cloudflare 公開網站。

工作環境未連接正式 Supabase 管理權限，無法代為執行。SQL 已以本機隔離資料庫及模擬既有 420 API 驗證；正式 420 函式與資料表仍需以實際專案為準。
